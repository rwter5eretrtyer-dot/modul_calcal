## Матрица ветвей `Calculate`

| Условие | True | False |
|:---|:---|:---|
| `request.Days <= 0` | T03 / T04 | T01, T02, T05-T08 |
| `request.IncludeInsurance` (после проверки Days) | T02 / T06 | T01, T05, T07, T08 |

Все четыре логические ветви доступны через подготовленные тесты. **Фактический процент покрытия** будет определён инструментом Coverlet после запуска в среде с .NET SDK; таблица не является измерением покрытия.
